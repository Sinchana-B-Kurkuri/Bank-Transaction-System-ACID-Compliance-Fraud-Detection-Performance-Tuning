# EXP-16 backup, restore and PITR (Member A)

Pre-run HYPOTHESIS (executed and blocked paths are distinguished in RESULTS.md): dump-only restores S0 and loses post-dump commits; replay to the pre-DELETE transaction boundary restores S1; replay to the pre-loss position restores S2. Native checksums are compared for all nine A tables, and logical JSON comparison is reported separately if binary JSON checksums change.

Prerequisites: mysqldump/mysqlbinlog beside the configured mysql.exe, MySQL 8.x binlogging, dump privileges, scratch rebuild permission. Replay additionally requires local binlog file read permission. Follow [the backup runbook](../../backup/README.md) for the exact six-command chain. All experiments are automated native MySQL operations; no service interruption is needed. Sessions must be otherwise idle to keep S0/S1/S2 boundaries controlled.

Manual two-window equivalent: window A at t+0 takes backup and observes T0/binlog coordinate. At t+10 window B runs the 500-deposit workload and records S1/T1. At t+20 A records the next binlog position before DELETE FROM Loans, executes the deletion, and runs the final deposit to S2. At t+30 B drops scratch using the asserted simulate_loss script. At t+40 A restores and replays each variant. These offsets are guidance, not measured timing requirements; sequence completion matters. SHOW BINLOG EVENTS from the pre-delete position identifies the transaction and Delete_rows event; stop before the whole transaction, not in the middle of its row events.

AUTOMATED: execute backup/ps/{take_full_backup,apply_workload,oops_delete,simulate_loss,restore_and_pitr}.ps1 in that order; pass -Database bank_txn_scratch. Evidence is evidence/raw/EXP-16/<timestamp>/ with EV-EXP16-summary.md for the measured comparison. Dump/replay files stay in ignored backup/out/. Screenshots should include server NOW/VERSION, binlog positions, and timestamps shown in the artifacts. Raw SQL is never captured using UTF-16 redirection. Binlog ACL failures leave PITR NOT YET RUN while completing dump-only restoration.
